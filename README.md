## 🎀 Sobre o projeto

Este repositório foi criado para documentar minha jornada de aprendizado com **Kubernetes**, desde os conceitos fundamentais de orquestração de containers até a configuração, o gerenciamento e a execução de aplicações em ambientes Kubernetes.

A ideia é reunir anotações, comandos, exercícios e projetos práticos para acompanhar minha evolução e consolidar os conhecimentos adquiridos ao longo dos estudos. ♡

## ☸️ 01. Conhecendo o Kubernetes

Antes de começar as práticas, vamos estudar os principais conceitos:

- O que é Kubernetes;
- Orquestração de containers;
- Diferenças e relação entre Docker e Kubernetes;
- Clusters e Nodes;
- Control Plane;
- Arquitetura do Kubernetes.

## 🧩 02. Minha trilha de estudos

Os principais assuntos que pretendo estudar e praticar:

- Introdução ao Kubernetes;
- Arquitetura e componentes de um Cluster;
- Pods e Containers;
- Deployments e ReplicaSets;
- Services e comunicação entre aplicações;
- ConfigMaps e Secrets;
- Volumes e persistência de dados;
- Configuração de ambientes Kubernetes;
- Projetos práticos.

## 🌷 Objetivo

Construir uma base sólida em Kubernetes, compreender os conceitos de orquestração de containers e desenvolver habilidades práticas para implantar, gerenciar e escalar aplicações.

Quero complementar meus conhecimentos em Git, Docker e Kubernetes, explorando ferramentas importantes para o desenvolvimento e a infraestrutura de aplicações.
